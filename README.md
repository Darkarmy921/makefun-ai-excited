One image made to excite the AI judge: a joyful golden retriever astronaut
grinning inside his helmet in a candy-coloured nebula — a huge face, a big
smile, saturated magenta, orange and cyan clouds, and Earth glowing in the
distance. Instantly legible at a glance, surprising and delightful: the kind
of picture a vision judge picks first in a pair.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
# writes out/entry.png (1024x1024 PNG, 496,575 bytes)
```

The program only copies `entry.png` (held in this repository) to
`/output/entry.png`. Deterministic: two runs write identical bytes.
No network, no dependencies beyond Python 3.13's standard library.
